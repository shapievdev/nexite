# Мессенджер на двоих

Приватный чат для двух человек на Laravel 13. Вход — по личному 4-значному коду,
без регистрации, почты и паролей. Один общий диалог, реальное время без внешних
сервисов (короткий поллинг), SQLite, никакой сборки фронтенда.

## Запуск

```bash
composer run setup     # зависимости, .env, ключ, база и два участника
composer run dev       # http://127.0.0.1:8000
```

`setup` создаёт двух участников и **один раз печатает их случайные коды** —
запишите их сразу. Повторный запуск сидера коды не трогает.

Откройте чат в двух разных браузерах (или в обычном окне и в приватном) и
войдите разными кодами — переписка пойдёт в реальном времени.

## Коды доступа

На экране входа нет ни имён, ни списка участников — только четыре клетки под
код. Кто вы, определяет сам код.

Сменить из чата: меню (⋮) → «Сменить код доступа».

Из терминала:

```bash
php artisan chat:code alice 8473   # задать конкретный
php artisan chat:code bob --random # выдать случайный
php artisan chat:code              # спросит участника и код
```

Коды хранятся только в виде bcrypt-хеша: восстановить забытый код нельзя,
можно лишь назначить новый.

Очевидные комбинации не принимаются: одинаковые цифры (`0000`, `7777`) и идущие
подряд в любую сторону (`1234`, `9876`, `0123`). Занять код собеседника тоже
нельзя — иначе войти под ним стало бы невозможно.

## Возможности

**Сообщения**
- текст с переносами строк, автоссылки, эмодзи-панель на ~350 символов;
- ответ на сообщение с цитатой и переходом к оригиналу;
- редактирование своих сообщений (сутки) с пометкой «изм.»;
- удаление своих сообщений — у обоих участников;
- закрепление сообщений с плашкой в шапке;
- реакции эмодзи (тап по реакции — снять/поставить);
- статусы доставки: ✓ отправлено, ✓✓ прочитано;
- разделители дат, группировка серий сообщений, линия непрочитанного.

**Вложения**
- фото с превью и просмотром на весь экран, видео и аудио с плеером;
- любые файлы до 25 МБ с прогрессом загрузки;
- перетаскивание в окно и вставка картинки из буфера (Ctrl+V);
- голосовые сообщения: запись с микрофона, живая осциллограмма,
  свой плеер с перемоткой по волне.

**Общение**
- «в сети» / «был(а) N минут назад», индикатор «печатает…»;
- звуковой сигнал и уведомления браузера о новых сообщениях;
- счётчик непрочитанного в заголовке вкладки и на кнопке «вниз».

**Приложение (PWA)**
- ставится на телефон и компьютер, запускается в своём окне без адресной строки;
- иконка — фото кота, в том числе maskable-вариант для Android;
- push-уведомления о новых сообщениях, когда чат закрыт;
- офлайн-заглушка вместо ошибки браузера при обрыве связи.

**Интерфейс**
- тёмная и светлая темы;
- поиск по переписке с подсветкой и переходом к сообщению;
- профиль: имя, «о себе», цвет и фото аватара;
- подгрузка истории при прокрутке вверх, черновик переживает перезагрузку;
- контекстное меню по правому клику и долгому тапу, адаптив под телефон;
- горячие клавиши: `Enter` — отправить, `Shift+Enter` — перенос строки,
  `↑` в пустом поле — правка последнего сообщения, `Ctrl/⌘+F` — поиск,
  `Esc` — закрыть панель или отменить ответ.

## Установка приложения и уведомления

**Поставить приложение.** Chrome и Edge покажут кнопку установки в адресной
строке, а в меню чата (⋮) появится пункт «Установить приложение». На iPhone —
«Поделиться» → «На экран „Домой“». На Android — «Установить приложение»
в меню браузера.

**Включить уведомления.** Меню (⋮) → «Уведомления» → разрешить в браузере.
Проверить доставку — «Прислать проверочное»: уведомление придёт на все
устройства, где вы включили их под этим кодом.

Уведомление отправляется собеседнику только если его нет в чате (не было
активности 25 секунд). Пока вкладка открыта, о сообщении сообщает сама
страница — так уведомление не приходит дважды.

Ключи VAPID создаются автоматически при `composer run setup`. Пересоздать:

```bash
php artisan chat:vapid --force   # все устройства придётся подписать заново
```

**Важно про HTTPS.** Service worker и push работают только на `localhost`
(`127.0.0.1`) или по HTTPS. На обычном `http://` по локальной сети браузер
их отключит. Для телефона в домашней сети подойдёт любой туннель
(`cloudflared`, `ngrok`) или свой сертификат.

**Про iOS.** Push доступен с iOS 16.4 и только после добавления на экран
«Домой» — в Safari на вкладке уведомления не приходят.

## Как устроено

| Слой | Где |
| --- | --- |
| Маршруты | `routes/web.php` |
| Вход по коду | `app/Http/Controllers/AuthController.php` |
| Чат и API | `app/Http/Controllers/ChatController.php` |
| Профиль | `app/Http/Controllers/ProfileController.php` |
| Модели | `app/Models/{User,Message,Reaction,PushSubscription}.php` |
| Присутствие | `app/Http/Middleware/TrackPresence.php` |
| Экраны | `resources/views/{login,chat,offline}.blade.php` |
| Клиент | `public/js/chat.js`, `public/css/app.css` |
| PWA | `public/sw.js`, `app/Http/Controllers/PwaController.php`, `public/icons/` |
| Push | `app/Services/PushSender.php`, `app/Jobs/NotifyPeerOfMessage.php`, `app/Http/Controllers/PushController.php` |
| Участники | `database/seeders/DatabaseSeeder.php` |

Аутентификация — штатный `web`-guard Laravel: код проверяется через `Hash::check`
по обоим участникам, дальше `Auth::login(..., remember: true)`. Все чат-маршруты
закрыты middleware `auth`.

Реальное время — опрос `GET /api/sync?last_id=&since=` раз в 1,5 секунды
(раз в 5 секунд, когда вкладка скрыта). Ответ содержит новые сообщения, изменения
существующих (правки, удаления, реакции, отметки о прочтении), статус собеседника
и список закреплённого. Broadcasting, Reverb, Redis и очереди не нужны.

Вложения лежат вне `public/` (`storage/app/private/chat`) и отдаются только
авторизованному участнику через `GET /attachments/{message}`.

Push уходит через `dispatchAfterResponse()`: отправитель получает ответ сразу,
а поход к push-сервису происходит уже после этого, в том же процессе. Отдельный
воркер очередей поднимать не нужно. Протухшие подписки (404/410 от сервиса)
удаляются автоматически.

Service worker кэширует только оболочку — стили, скрипт, иконки и страницу
«нет сети». Переписка, вложения и `/api/*` не кэшируются никогда: приватным
данным не место в дисковом кэше браузера.

правку и удаление, реакции, прочтение, «печатает…», поиск, загрузка файлов и

офлайн-собеседнику и её отсутствие для того, кто уже в чате.

## Развёртывание на своём сервере

1. `APP_ENV=production`, `APP_DEBUG=false`, свой `APP_URL`.
2. Обязательно HTTPS: 4-значный код — короткий секрет, по HTTP его видно в сети.
   Плюс без HTTPS не заработают ни установка приложения, ни push.
3. `SESSION_SECURE_COOKIE=true`.
4. `php artisan config:cache route:cache view:cache`.
5. Корень веб-сервера — папка `public/`, права на запись — `storage/` и
   `database/database.sqlite`.
6. `VAPID_*` перенести в продакшн-`.env` как есть — иначе подписанные устройства
   отвалятся и уведомления придётся включать заново.

Подбор кода ограничен: 8 неверных попыток с одного IP — блокировка на минуту.
Для чата на двоих этого достаточно, но не выкладывайте его в публичный интернет
без HTTPS.
